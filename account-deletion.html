Account deletion

Account deletion is not available yet. This is an information page, not a working deletion-request form. The current Supabase identity is shared with another project, and deleting that identity could remove access to data outside this app.

A safe app-specific deletion workflow has not yet been implemented. The maintainer must first separate this app's account/data lifecycle from the shared identity service, build and test deletion of messages, attachments, profile data, notification tokens and related records, and add a private request channel.

Public Google Play release is blocked until both an in-app account-deletion option and a working web-based deletion-request path are available. The public project issue tracker is not a private deletion channel; do not post personal details, passwords or private messages there.
